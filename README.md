# App & Website Redesign Concepts

This repository contains 5 UI/UX redesign concepts for popular apps and websites.  
Each project focuses on improving user experience, modern visuals, and cleaner interface design.

---

## Projects Included

### 1. Spotify Redesign
A modern redesign of the Spotify music streaming app.  
Improved navigation, better personalization, and refined dark theme experience.

**Key Screens:** Home, Search, Playlist, Player, Profile  


---

### 2. Food Delivery App Redesign
A clean and user-friendly redesign of a food delivery application.  
Focus on faster ordering, better restaurant discovery, and smooth checkout flow.

**Key Screens:** Home, Restaurant Menu, Cart, Order Tracking, Profile  


---

### 3. Notion Redesign
A simplified and modern redesign of the Notion productivity app.  
Improved hierarchy, cleaner sidebar, and better visual structure.

**Key Screens:** Dashboard, Notes, Database View, Templates, Settings  


---

### 4. Banking App Redesign
A trustworthy and minimal redesign of a mobile banking application.  
Focus on simplicity, clarity, and secure user experience.

**Key Screens:** Dashboard, Money Transfer, Cards, Transactions, Profile  


---

### 5. E-commerce Website Redesign
A complete redesign of a modern online shopping website.  
Improved product discovery, clean product pages, and smooth checkout experience.

**Key Screens:** Homepage, Product Listing, Product Detail, Cart, Checkout  


---

## Design Approach

- Modern and clean UI design
- Strong focus on user experience
- Consistent spacing and visual hierarchy
- Mobile-first approach
- Style guide included for each project

---

## Tools Used

- Figma / Adobe XD / Photoshop

## How to View

Har project ke folder mein:

- `mockups/` → Device mockups
